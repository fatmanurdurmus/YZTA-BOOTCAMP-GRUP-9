# Sample Documents for CarbonPilot Ingestion & Extractor Testing

This directory contains reference test documents used to validate document extraction, structure parsing, and schema generation pipeline.

## Files
1. `sample_invoice.pdf` / `sample_invoice.docx` — Sample Natural Gas Purchase Invoice with activity data (kWh/m3).
2. `sample_activity_export.xlsx` — Excel activity export containing energy and fuel consumption values.
